# Function Lab — Python-дағы функциялар

Бұл — Қ. Жұбанов атындағы Ақтөбе өңірлік университетінің «Python-да қосымшалар
құру» пәні бойынша ашық практикалық сабаққа арналған толық жұмыс істейтін оқу
сайты. Тақырып: **Python-дағы функциялар** («Қайталанатын кодтан шағын
қосымшаға»).

Сайт екі бөліктен тұрады:

- **Студенттік бет** (`/`) — HTML, CSS және қарапайым JavaScript. Python коды
  шынайы орындалады — **Pyodide** (Python-ды браузерде орындайтын WebAssembly
  ортасы) арқылы.
- **Оқытушының әкімші панелі** (`/admin/`) — парольмен қорғалған бет: толық
  сабақ жоспары (әр кезеңде нақты не айту керегі), жауап кілті, бағалау
  дескрипторлары және студенттер жіберген жауаптардың, жұптық код
  алмасудың тікелей (live) кестесі.

Екеуін де қарапайым **Node.js сервері** қамтамасыз етеді — студенттердің
жауаптары мен жұптық код алмасуы сол сервер арқылы орталықтандырылып
жиналады.

## 1. Құрылымы

```
api/
  [...path].js          — Vercel serverless функциясы: /api/* сұрауларын Express-ке береді
server/
  server.js            — Express сервері: статикалық сайтты береді + API
  store.js              — дерекқор диспетчері (DATABASE_URL бар/жоқтығына қарай таңдайды)
  store.pg.js            — Neon/Postgres нұсқасы (production)
  store.json.js           — жергілікті JSON-файл нұсқасы (DATABASE_URL жоқ кезде)
  pairs.js               — жұптасу кестесі (1-2, 3-4, 5-6, 7-8)
  lesson-plan.js          — оқытушының толық сценарийі (тек /admin арқылы көрінеді)
public/
  index.html             — студенттік бет (барлық 6 бөлім осында)
  css/style.css           — дизайн
  js/data.js               — сабақ мәтіні, 8 нұсқаның деректері, формулалар
  js/storage.js            — localStorage арқылы сақтау + studentId
  js/editor.js             — код редакторы компоненті
  js/worker.js             — Pyodide-ды жүктейтін Web Worker
  js/pyrunner.js            — worker-мен байланысты басқаратын қабат
  js/app.js                 — беттің негізгі логикасы (навигация, бөлімдер, сервер сұраулары)
  admin/
    index.html               — әкімші панелінің беті (`/admin/`)
    admin.css, admin.js       — панельдің дизайны мен логикасы

  submissions.json         — DATABASE_URL жоқ кезде ғана жасалады (git-ке түспейді)
package.json              — тәуелділіктер: express, @neondatabase/serverless
teacher-guide.md          — басылып шығарылатын офлайн нұсқа (жауап кілті, уақыт картасы)
README.md                 — осы файл
```

## 2. Жергілікті іске қосу

```bash
cd funcs_py
npm install
npm start
```

Сервер `http://localhost:3000` мекенжайында іске қосылады:

- студенттер үшін: `http://localhost:3000/`
- оқытушы үшін: `http://localhost:3000/admin/`

Порт нөмірін өзгерту үшін `PORT` ортa айнымалысын қолданыңыз
(мыс. `PORT=8080 npm start`).

## 3. Әкімші паролі

Әкімші панеліне кіру үшін пароль қажет. Әдепкі бойынша ол — `ustaz2026`
(тек жергілікті сынақ үшін). **Нақты серверге (интернетке) шығармас бұрын
міндетті түрде өз паролінізді орнатыңыз:**

```bash
ADMIN_PASSWORD="менің_құпия_паролім" npm start
```

Хостинг провайдерінде (төмендегі 4-бөлімді қараңыз) бұл мән әдетте
«Environment Variables» бөлімінде орнатылады.

Қауіпсіздік туралы ескерту: бұл — күрделі көпсатылы авторизация емес,
сыныптағы бір топ үшін жеткілікті қарапайым, ортақ парольге негізделген
қорғаныс. Құпия деректерді (баға тізімі, жеке мәліметтер) сақтауға арналмаған.

## 4. Интернетке шығару — Vercel + Neon (ұсынылатын жол)

Жоба Vercel-дің «статикалық сайт + serverless функция» үлгісіне дайын:

- `public/` — Vercel автоматты түрде статикалық файл ретінде береді.
- `api/[...path].js` — барлық `/api/*` сұрауларын Express қосымшасына
  (`server/server.js`) бағыттайтын жалғыз serverless функция.
- `server/store.pg.js` — `DATABASE_URL` орта айнымалысы бар болса, деректерді
  Neon Postgres-те сақтайды (кестелер бірінші сұрауда автоматты жасалады —
  бөлек миграция қадамы қажет емес).

**Қадамдар (екеуі де — Vercel мен Neon-ның ресми Marketplace интеграциясы,
құпия сөз ешқайда қолмен көшірілмейді):**

1. **Vercel жобасын жасау:** https://vercel.com/new — GitHub аркылы кіріп,
   `ush-zhuz-bes/funcs_py` репозиторийін импорттаңыз. Framework preset:
   «Other». Build command бос қалсын (қажет емес). «Deploy» басыңыз.
2. **Neon дерекқорын қосу:** жаңа жобаңыздың Vercel парақшасында
   **Storage → Connect Database → Neon** (немесе
   https://vercel.com/integrations/neon) арқылы Neon-ды қосыңыз. Бұл
   автоматты түрде жаңа Neon жобасы мен Postgres дерекқорын жасап,
   `DATABASE_URL`-ды сол Vercel жобасының **серверлік** орта
   айнымалыларына өзі жазады — сізге ешқандай пароль көшірудің қажеті жоқ.
3. **Әкімші паролін орнату:** Vercel жобасында **Settings → Environment
   Variables** бөліміне өтіп, `ADMIN_PASSWORD` айнымалысын (Production)
   қосыңыз. Бұл қадамды орындамасаңыз, әдепкі `ustaz2026` паролі қолданыла
   береді — нақты сыныпта міндетті түрде өзгертіңіз.
4. Env var қосқаннан кейін жобаны қайта деплой етіңіз (Vercel
   «Redeploy» батырмасы немесе жаңа commit).
5. Дайын болған соң: студенттерге `https://<жоба-атауы>.vercel.app/`,
   өзіңізге `https://<жоба-атауы>.vercel.app/admin/` сілтемесін пайдаланыңыз.

Осыдан кейінгі әрбір `git push` автоматты түрде жаңа деплой жасайды
(GitHub ↔ Vercel байланысы арқылы) — қолмен ештеңе жүктеудің қажеті жоқ.

**Балама хостинг:** жоба кез келген басқа Node.js хостингінде (Render,
Railway, Fly.io, VPS) де жұмыс істейді — `npm install` + `npm start`
(`node server/server.js`), `PORT`, `ADMIN_PASSWORD` және (қаласаңыз)
кез келген Postgres провайдерінің `DATABASE_URL`-ын орнатыңыз. `DATABASE_URL`
болмаса, сервер жергілікті `data/submissions.json` файлына сақтайды — бұл
тек жергілікті сынақ үшін ыңғайлы, тұрақты (persistent disk жоқ) хостингте
деректер жоғалуы мүмкін.

## 5. Интернет қажеттілігі (Python орындау үшін)

Студенттік беттің өзі (мәтін, тапсырмалар, нұсқалар, навигация) интернетсіз
де толық ашылады. Бірақ **нақты Python кодын орындау үшін** браузер бір рет
Pyodide файлдарын интернеттен (`cdn.jsdelivr.net`) жүктеп алуы керек.

- Интернет бар болса: бірінші жүктеуден кейін браузер Pyodide файлдарын
  кэштейді, келесі ашуларда жылдамырақ жүктеледі.
- Интернет жоқ немесе CDN қолжетімсіз болса: сайт жоғарғы жолақта «Python
  ортасын жүктеу мүмкін болмады…» деп ашық хабарлайды. Бұл жағдайда да оқу
  мәтіні, тапсырмалар, нұсқалар, тест кестесі, жұптық алмасу (сервер арқылы,
  интернет/жергілікті желі жеткілікті), рефлексия және сақтау/жүктеу/жіберу
  мүмкіндіктері жұмыс істей береді — тек кодты сайт ішінде орындау мүмкін
  болмайды. Студент өз кодын **«.py жүктеу»** батырмасымен жүктеп алып,
  компьютерде орнатылған Python арқылы (`python variant_1.py`) өзі тексере
  алады.

Толық офлайн (интернетсіз) Python орындауды қамтамасыз ету үшін:

1. https://github.com/pyodide/pyodide жобасының `pyodide-314.0.7.tar.bz2`
   (немесе сәйкес) runtime архивін жүктеп алыңыз.
2. Оны `public/js/pyodide-vendor/` қалтасына шығарыңыз.
3. `public/js/worker.js` файлындағы `PYODIDE_CDN_URL` мәнін
   `"./pyodide-vendor/"` (салыстырмалы жол) етіп өзгертіңіз.
4. Серверді әдеттегідей іске қосыңыз — енді Python орындау үшін интернет
   қажет болмайды (сервердің өзі жергілікті желіде жұмыс істесе де жеткілікті).

Осы қадамдарды жасамасаңыз, Python орындау тек интернет бар кезде ғана
істейді деп есептеңіз.

## 6. Студент жұмысын жинау (екі жол)

1. **Автоматты (негізгі жол):** әр бөлімнің соңында «Жауаптарды оқытушыға
   жіберу» батырмасы бар. Оны басқанда сол студенттің ағымдағы коды, тест
   нәтижелері, шағын қорғау және рефлексия жауаптары серверге жіберіліп,
   `/admin/` панеліндегі кестеге дереу түседі (оқытушы «Жаңарту» батырмасын
   басуы керек). Студент бірнеше рет жібере алады — әр жіберу алдыңғысын
   жаңартады.
2. **Қосымша (сақтық көшірме):** «Қорытынды» бөліміндегі «Жұмысымды жүктеу»
   батырмасы студенттің жұмысын жеке `.html` файл етіп оның өз компьютеріне
   сақтайды — интернет/сервер істемей қалған жағдайда қолданылатын қосалқы жол.

## 7. Жұптық тексеру қалай жұмыс істейді

Нұсқалар тұрақты жұппен байланысқан: 1↔2, 3↔4, 5↔6, 7↔8
(`server/pairs.js` және `public/js/data.js` ішіндегі `PAIR_MAP`). «5. Тексеру»
бөліміндегі «Ә. Жұптық тексеру» ішінде:

1. Автор «Серіктеске кодымды жіберу» батырмасын басады — код серверге жіберіледі.
2. Серіктесі «Серіктестің кодын қарау» батырмасын басып, кодты өз экранынан
   оқиды да, тексеру парағын (жағдай, байқалған нәтиже, қорытынды) толтырып
   жібереді.
3. Автор «Маған келген пікірлерді көру» батырмасымен серіктесінің жазған
   пікірін өз экранынан көреді.

Рөл ауысқанда (37–41 мин) екінші жақ та дәл осылай өз кодын жібереді. Барлық
алмасу `/admin/` панеліндегі «Жұптық алмасу мониторы» бөлімінде де көрінеді.

## 8. Оқытушыға арналған материал

Екі жерде бар:

- **`/admin/` панелі** (интерактивті, парольмен қорғалған) — толық сабақ
  сценарийі (әр кезеңде нақты не айту керек), жауап кілті, бағалау
  дескрипторлары және студенттердің тікелей жауаптары. Негізгі жұмыс құралы
  осы.
- **`teacher-guide.md`** — сол материалдың басылып шығаруға/офлайн қарауға
  ыңғайлы, статикалық нұсқасы (интернет/сервер болмаған жағдайда сақтық
  көшірме ретінде).

Екеуін де студенттерге таратпаңыз.

## 9. Браузер талаптары

Соңғы нұсқадағы Chrome, Edge немесе Firefox ұсынылады (ES Modules және Web
Worker (module type) қолдауы қажет). Ескі браузерлерде (Internet Explorer)
сайт жұмыс істемейді.

## 10. Pyodide нұсқасы

Жоба `Pyodide v314.0.7` (CPython 3.14.2) нұсқасына бекітілген
(`public/js/worker.js` файлындағы `PYODIDE_VERSION`). Нұсқаны жаңартқыңыз
келсе, тек осы бір жерді өзгертіп, сайтты толық қайта тексеріңіз — әртүрлі
нұсқалардың runtime файлдарын араластырмаңыз.
