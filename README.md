# Function Lab — Python-дағы функциялар

Бұл — Қ. Жұбанов атындағы Ақтөбе өңірлік университетінің «Python-да қосымшалар
құру» пәні бойынша ашық практикалық сабаққа арналған толық жұмыс істейтін оқу
сайты. Тақырып: **Python-дағы функциялар** («Қайталанатын кодтан шағын
қосымшаға»).

Сайт тек **HTML, CSS және қарапайым (кітапханасыз) JavaScript** арқылы
жасалған. Python коды шынайы орындалады — ол үшін сайт **Pyodide** (Python-ды
браузерде орындайтын WebAssembly ортасы) қолданады.

## 1. Құрылымы

```
index.html            — негізгі бет (барлық 6 бөлім осында)
css/style.css          — дизайн
js/data.js              — сабақ мәтіні, 8 нұсқаның деректері, формулалар
js/storage.js           — localStorage арқылы сақтау
js/editor.js            — код редакторы компоненті
js/worker.js            — Pyodide-ды жүктейтін Web Worker
js/pyrunner.js           — worker-мен байланысты басқаратын қабат
js/app.js                — беттің негізгі логикасы (навигация, бөлімдер)
teacher-guide.md        — тек оқытушыға арналған материал (студентке таратпаңыз)
README.md               — осы файл
```

## 2. Қалай ашу керек (міндетті түрде жергілікті сервер арқылы)

Файлды тікелей браузерде екі рет басып ашуға **болмайды** (`file://` арқылы),
себебі заманауи браузерлер қауіпсіздік үшін модульдік JavaScript пен Web
Worker-ді `file://` хаттамасында оқшаулайды. Сайтты жергілікті HTTP сервер
арқылы ашу керек:

**Python орнатылған болса (ең қарапайым жол):**

```bash
cd funcs_py
python3 -m http.server 8000
```

Содан кейін браузерде ашыңыз: `http://localhost:8000/`

**Немесе Node.js арқылы:**

```bash
npx http-server funcs_py -p 8000
```

**Немесе VS Code қолдансаңыз:** «Live Server» кеңейтімін орнатып, `index.html`
файлын тінтуірдің оң жақ батырмасымен басып, «Open with Live Server» таңдаңыз.

Университеттің компьютер сыныбында сайтты бір рет осылай іске қосып, оны
барлық 8 компьютерге көшіруге немесе ортақ желі дискісінен ашуға болады —
маңыздысы, әрқашан `http://` немесе `https://` арқылы ашылуы.

## 3. Интернет қажеттілігі

Сайттың өзі (мәтін, тапсырмалар, нұсқалар, навигация) интернетсіз де толық
ашылады және жұмыс істейді. Бірақ **нақты Python кодын орындау үшін** браузер
бір рет Pyodide файлдарын интернеттен (`cdn.jsdelivr.net`) жүктеп алуы керек.

- Интернет бар болса: бірінші жүктеуден кейін браузер Pyodide файлдарын
  кэштейді, келесі ашуларда жылдамырақ жүктеледі.
- Интернет жоқ немесе CDN қолжетімсіз болса: сайт жоғарғы жолақта «Python
  ортасын жүктеу мүмкін болмады…» деп ашық хабарлайды. Бұл жағдайда да оқу
  мәтіні, тапсырмалар, нұсқалар, тест кестесі, жұптық тексеру, рефлексия және
  сақтау/жүктеу мүмкіндіктері жұмыс істей береді — тек кодты сайт ішінде
  орындау мүмкін болмайды. Студент өз кодын **«.py жүктеу»** батырмасымен
  жүктеп алып, компьютерде орнатылған Python арқылы (`python variant_1.py`)
  өзі тексере алады.

**Назар аударыңыз:** бұл нұсқа толық офлайн жұмыс істейтін Pyodide орнатуын
қамтымайды — Python орындау тек интернет арқылы CDN-нен жүктелгенде ғана
істейді. Толық офлайн (интернетсіз) Python орындауды қамтамасыз ету үшін:

1. https://github.com/pyodide/pyodide жобасының `pyodide-314.0.7.tar.bz2`
   (немесе сәйкес) runtime архивін жүктеп алыңыз.
2. Оны осы жобаның `js/pyodide-vendor/` қалтасына шығарыңыз.
3. `js/worker.js` файлындағы `PYODIDE_CDN_URL` мәнін
   `"./pyodide-vendor/"` (салыстырмалы жол) етіп өзгертіңіз.
4. Сайтты жоғарыдағыдай жергілікті HTTP сервер арқылы ашыңыз — енді интернет
   болмаса да Python орындалады.

Осы қадамдарды жасамасаңыз, сайт тек интернет бар кезде ғана нақты Python
кодын орындайды деп есептеңіз.

## 4. Студент жұмысын жинау

Сайт серверге ештеңе жібермейді (бэкенд жоқ, тіркелу жоқ). Әр студент:

1. Жұмысын браузерде істейді — код пен жауаптар сол компьютердің браузерінде
   (`localStorage`) автоматты сақталады.
2. Сабақ соңында **«Қорытынды»** бөлімінде **«Жұмысымды жүктеу»** батырмасын
   басып, `jumys_esebi_<аты>.html` файлын өз компьютеріне сақтайды.
3. Осы файлды (қажет болса, `.py` файлдарын да) оқытушы көрсеткен жерге
   (электрондық пошта, оқу порталы, флеш-жады т.б.) өзі жібереді.

Сайт «оқытушыға автоматты жіберілді» дегенді ешқашан көрсетпейді — жіберу
әрекетін студент өзі жасайды.

## 5. Браузер талаптары

Соңғы нұсқадағы Chrome, Edge немесе Firefox ұсынылады (ES Modules және Web
Worker (module type) қолдауы қажет). Ескі браузерлерде (Internet Explorer)
сайт жұмыс істемейді.

## 6. Pyodide нұсқасы

Жоба `Pyodide v314.0.7` (CPython 3.14.2) нұсқасына бекітілген
(`js/worker.js` файлындағы `PYODIDE_VERSION`). Нұсқаны жаңартқыңыз келсе,
тек осы бір жерді өзгертіп, сайтты толық қайта тексеріңіз — әртүрлі
нұсқалардың runtime файлдарын араластырмаңыз.
