1. Қайталау 0–13 минут

Бұрын өткен материалды еске түсірейік: жиын (set) және сөздік (dict) деген не, олар бір-бірінен немен ерекшеленеді. Бұл бөлім шамамен 10–13 минутқа есептелген.

1-сұрақ. Жиын (set) дегеніміз не?

Жиын — қайталанбайтын, реттелмеген элементтерден тұратын жиынтық. Python-да set() функциясымен немесе ішінде кемінде бір элементі бар {} фигуралық жақшамен жасалады.

2-сұрақ. Set қайталанатын элементтерді қалай өңдейді?

Жиынға қайталанатын мән қанша рет қосылса да, ол тек бір рет сақталады. Мысалы, set([1, 2, 2, 3]) нәтижесінде {1, 2, 3} шығады — себебі жиынның негізгі қасиеті: әр элемент бірегей.

3-сұрақ. set() пен {} арасында қандай айырма бар?

{} — бос сөздік (dict) жасайды, бос жиын емес! Ал бос жиынды тек set() арқылы ғана жасауға болады. Егер ішінде элемент болса (мысалы, {1, 2, 3}), бұл жиын (set) болады.

4-сұрақ. Сөздікте кілт (key) пен мән (value) деген не?

Сөздік — кілт: мән жұптарынан тұратын құрылым. Кілт арқылы тиісті мәнге жылдам қол жеткізуге болады. Мысалы, {'name': 'Asan'} жазбасында 'name' — кілт, 'Asan' — осы кілтке сәйкес мән.

5-сұрақ. dict.get() пен dict[key] арасында қандай айырма бар?

dict[key] — егер мұндай кілт сөздікте болмаса, KeyError қатесін тудырады. dict.get(key, әдепкі_мән) — кілт болмаса, бағдарлама тоқтамайды, орнына көрсетілген әдепкі мәнді (немесе кілт берілмесе None) қайтарады.

Негізгі код

Python 
values = [1, 2, 3, 1, 2]
numbers = set(values)
print(sorted(numbers))

empty_set = set()
empty_dict = {}
print(type(empty_set), type(empty_dict))

Жолма-жол түсіндірме:

  • values = [1, 2, 3, 1, 2] — қайталанатын сандары бар тізім жасалды.
  • numbers = set(values) — тізімнен жиын жасалады, қайталанған 1 мен 2 бір-бірден ғана қалады.
  • print(sorted(numbers)) — жиын элементтерінің реті тұрақты болмағандықтан, sorted() арқылы өсу ретімен тізім ретінде шығарамыз.
  • empty_set = set() — бос жиын жасалды.
  • empty_dict = {} — бос сөздік жасалды (назар аударыңыз: {} жиын емес!).
  • print(type(empty_set), type(empty_dict)) — екі айнымалының нақты түрін (типін) шығарады.
Күтілетін нәтиже: 
[1, 2, 3]
<class 'set'> <class 'dict'>

2. Жиындар 13–24 минут

Дереккөз: №8 дәріс «Жиындар», оқу-әдістемелік кешен, 67–74-беттер.

Негізгі ұғымдар мен операциялар

  • set() немесе {} (бос емес) — жиын жасау
  • len(a) — жиындағы элементтер саны
  • x in a — элементтің жиында бар-жоғын тексеру
  • a | b немесе a.union(b) — бірігу (union)
  • a & b немесе a.intersection(b) — қиылысу (intersection)
  • a - b немесе a.difference(b) — айырым (difference)
  • a ^ b немесе a.symmetric_difference(b) — симметриялық айырым
  • a.add(x) — жиынға элемент қосу
  • a.remove(x) — элементті жою (жоқ болса KeyError)
  • a.discard(x) — элементті жою (жоқ болса қате болмайды)

Ескерту: жиынды print() арқылы шығарғанда элементтердің реті тұрақты емес (Python бұған кепілдік бермейді). Сондықтан бұл сабақта нәтижелерді салыстырғанда әрқашан sorted() функциясын қолданамыз.

frozenset — өзгермейтін (immutable) жиын. Әдеттегі жиынмен бірдей операцияларды (|, &, -, ^) қолдауға болады, бірақ оған add() немесе remove() арқылы өзгеріс енгізу мүмкін емес. Сондықтан оны, мысалы, сөздіктің кілті ретінде немесе басқа жиынның ішіндегі элемент ретінде қолдануға болады.

Негізгі мысал

Python 
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}
print('Бірігуі:', sorted(a | b))
print('Қиылысуы:', sorted(a & b))
print('Айырымы:', sorted(a - b))
print('Симметриялық айырым:', sorted(a ^ b))

Жолма-жол түсіндірме:

  • a = {1, 2, 3, 4, 5} және b = {4, 5, 6, 7, 8} — екі жиын жасалды.
  • a | b — екі жиынның барлық (қайталанбайтын) элементтерін біріктіреді.
  • a & b — тек екі жиында да бар ортақ элементтерді алады.
  • a - b — тек a-да бар, бірақ b-де жоқ элементтер.
  • a ^ b — екі жиынның біреуінде ғана кездесетін элементтер (ортақтары алынып тасталады).
Күтілетін нәтиже: 
Бірігуі: [1, 2, 3, 4, 5, 6, 7, 8]
Қиылысуы: [4, 5]
Айырымы: [1, 2, 3]
Симметриялық айырым: [1, 2, 3, 6, 7, 8]

Қосымша мысал: add() және discard()

Python 
numbers = {1, 2, 3, 4, 5, 6}
numbers.discard(3)
numbers.add(8)
print(sorted(numbers))

Жолма-жол түсіндірме:

  • numbers.discard(3) — жиыннан 3 санын жояды.
  • numbers.add(8) — жиынға 8 санын қосады.
  • print(sorted(numbers)) — нәтижені өсу ретімен шығарады.
Күтілетін нәтиже: 
[1, 2, 4, 5, 6, 8]

Маңызды айырма: егер remove() жиында жоқ элементті өшіруге тырысса, Python KeyError қатесін тудырады да, бағдарлама тоқтайды. Ал discard() дәл сол жағдайда ешқандай қате бермейді — жиында элемент болмаса, жай ештеңе істемейді.

3. Сөздіктер 24–36 минут

Дереккөз: №9 дәріс «Сөздіктер түсінігі және құру принциптері», оқу-әдістемелік кешен, 74–80-беттер.

Негізгі ұғымдар мен операциялар

  • {key: value} — сөздік жазылымы
  • d[key] — кілт бойынша мәнге қатынау
  • d[new_key] = value — жаңа жазба қосу
  • d[key] = new_value — бар мәнді өзгерту
  • d.get(key, default) — кілт жоқ болса, қатесіз әдепкі мән қайтарады
  • d.keys(), d.values(), d.items() — кілттер, мәндер, жұптар бойынша айналып шығу
  • d.update(other) — сөздікті басқа сөздікпен толықтыру/жаңарту
  • dict.fromkeys(iterable, value) — бірдей мәнмен сөздік жасау
  • dict(zip(keys_list, values_list)) — екі тізімнен сөздік құру
  • Сөздіктер тізімі (list ішінде бірнеше dict) — бір типтегі жазбалар топтамасын сақтауға ыңғайлы

Негізгі мысал

Python 
student = {'name': 'Asan', 'age': 20}
student['city'] = 'Aktobe'
student['age'] = 21
print(student['name'])
print(student.get('phone', 'мәлімет жоқ'))
for key, value in student.items():
    print(key, value)

Жолма-жол түсіндірме:

  • student = {'name': 'Asan', 'age': 20} — екі жазбасы бар сөздік жасалды.
  • student['city'] = 'Aktobe' — сөздікке жаңа кілт-мән жұбы қосылды.
  • student['age'] = 21 — бар кілттің мәні жаңартылды (20 орнына 21).
  • print(student['name']) — 'name' кілтінің мәнін шығарады.
  • student.get('phone', 'мәлімет жоқ') — сөздікте 'phone' кілті жоқ, сондықтан қате шықпай, әдепкі мән қайтарылады.
  • for key, value in student.items(): — сөздіктің барлық кілт-мән жұптарын, енгізілген ретімен, бір-бірлеп шығарады.
Күтілетін нәтиже: 
Asan
мәлімет жоқ
name Asan
age 21
city Aktobe

Қосымша мысал: zip() арқылы сөздік құру

Python 
fields = ['name', 'age', 'job']
values = ['Dina', 22, 'developer']
record = dict(zip(fields, values))
print(record['job'])

Жолма-жол түсіндірме:

  • fields — болашақ сөздіктің кілттері тізімі.
  • values — сол кілттерге сәйкес мәндер тізімі.
  • zip(fields, values) — екі тізімнің элементтерін жұп-жұбымен қосады: ('name', 'Dina'), ('age', 22), ('job', 'developer').
  • dict(...) — осы жұптардан дайын сөздік жасайды.
  • print(record['job']) — 'job' кілтінің мәнін шығарады.
Күтілетін нәтиже: 
developer

Маңызды ескерту: сөздіктің кілттері әрқашан бірегей (қайталанбайды) болуы керек. Қазіргі Python 3 нұсқасында (3.7 және одан кейінгі) сөздік элементтері енгізілген ретімен сақталады. Әдістемелік құралдың кейбір ескі басылымдарында сөздік «реттелмеген» деп сипатталуы мүмкін — бұл ескірген ақпарат, біз осы сабақта заманауи Python 3 тәртібін негізге аламыз.

4. Практикалық тапсырмалар 36–50 минут

Барлық 8 студент төмендегі үш тапсырманы орындайды. Алдымен өзіңіз шешуге тырысыңыз, қажет болса «Кеңесті ашу» бөлімін пайдаланыңыз.

1-тапсырма

Берілген тізімнен бірегей (қайталанбайтын) сандарды өсу ретімен шығарыңыз.

Бастапқы дерек: numbers = [4, 6, 4, 8, 6, 9]

Кеңесті ашу

set() арқылы қайталанатын элементтерді жойып алыңыз, одан кейін sorted() функциясымен өсу ретіне келтіріңіз.

Шешімді тексеруге арналған түсіндірме

Дұрыс нәтиже: [4, 6, 8, 9]. Тізімде 4 саны екі рет, 6 саны да екі рет қайталанған — set() оларды бір-бірден ғана қалдырады, ал sorted() нәтижені өсу ретімен тізімге келтіреді.

2-тапсырма

Берілген екі жиынның қиылысуын және A - B айырымын табыңыз.

Бастапқы дерек: A = {2, 4, 6, 8}, B = {4, 7, 8}

Кеңесті ашу

Қиылысу үшін & операторын, айырым үшін - операторын қолданыңыз. Нәтижені sorted() арқылы шығарыңыз.

Шешімді тексеруге арналған түсіндірме

Қиылысуы (A & B): {4, 8} — sorted() қолдансаңыз [4, 8]. Айырымы (A - B): {2, 6} — sorted() қолдансаңыз [2, 6].

3-тапсырма

Берілген сөздікте score мәнін 85-ке жаңартыңыз, жаңа dept кілтін қосыңыз, одан кейін name мен score мәндерін экранға шығарыңыз.

Бастапқы дерек: student = {'name': 'Dina', 'score': 75}

Кеңесті ашу

Мән өзгерту үшін student['score'] = 85, жаңа кілт қосу үшін student['dept'] = '...' деп жазыңыз (бөлім атауын өзіңіз таңдаңыз).

Шешімді тексеруге арналған түсіндірме

Дұрыс нәтижеде: score — 85, сөздікте dept кілті пайда болады (мәні — өзіңіз таңдаған бөлім атауы), name өзгеріссіз 'Dina' болып қалады.

Қорытынды сұрақтар

1. Қайталануды жою үшін қандай тип керек?

set (жиын) типі — себебі жиында әрбір элемент бірегей болады, қайталанатын мәндер автоматты түрде алынып тасталады.

2. Ат, жас, мамандық сияқты сипаттарды кілтпен сақтау үшін қандай тип тиімді?

dict (сөздік) типі — әр сипатты өзіндік кілтпен (мысалы 'аты', 'жасы', 'мамандығы') сақтауға және кілт арқылы тез табуға ыңғайлы.

2-есеп. Сөздік — Зертханалық №11 жұмыс, әдістемедегі 9-тапсырма (ПДФ 180–181-б.)

Тұрғындар санағының нәтижелері берілген болсын. 1990 ж. кейін туылған тұрғындардың фамилиясын, атын және жалпы санын анықтайтын программа құрыңыз.
