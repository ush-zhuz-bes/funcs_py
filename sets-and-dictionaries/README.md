# Жиындар мен сөздіктер — Python-да қосымшалар құру

Бұл — Қ. Жұбанов атындағы Ақтөбе өңірлік университетінің «Python-да қосымшалар құру»
пәні бойынша практикалық және зертханалық сабаққа арналған статикалық оқу сайты
(тақырыбы: «Жиындар мен сөздіктер», 3-курс, 5-семестр, 7-апта).

## Қалай ашу керек

Сервер де, дерекқор да, интернет байланысы да қажет емес:

1. `index.html`, `style.css`, `script.js` үш файлын бір қалтаға салыңыз (олар қазір де
   осы қалтада бірге жатыр).
2. `index.html` файлын кез келген браузерде (Chrome, Edge, Firefox) тікелей ашыңыз —
   қос басу жеткілікті, `file://` арқылы да толық жұмыс істейді.
3. Интернет қажет емес — сайт толығымен жергілікті жұмыс істейді, сыртқы
   кітапхана немесе қаріп жүктелмейді.

## Құрылымы

- **Практикалық сабақ**: 1. Қайталау → 2. Жиындар → 3. Сөздіктер → 4. Практикалық
  тапсырмалар.
- **Зертханалық сабақ**: 5. Менің нұсқам (1–8 нұсқадан біреуін таңдау) → 6. Қорытынды
  және тапсыру.

## Маңызды ескерту

Сайт Python кодын орындамайды және тексермейді — бұл әдейі істелген. Барлық код
мысалдарын студент өз компьютерінде орнатылған Python ортасында (IDLE, VS Code,
PyCharm және т.б.) өзі іске қосады. Сайт тек тапсырма мәтінін, бастапқы деректерді
және "Кодты көшіріп алу" мүмкіндігін ұсынады.

## Файлдар

- `index.html` — сайттың барлық мазмұны.
- `style.css` — көрініс (ашық, академиялық дизайн).
- `script.js` — навигация, тест жауаптарын ашу, нұсқа таңдау, көшіру, басып шығару.
- `teacher-notes.md` — тек оқытушыға арналған ішкі жазба, сайтта жарияланбаған.
