# Мұғалімге арналған жауап кілті (ІШКІ, сайтта ЖАРИЯЛАНБАҒАН)

Бұл файл тек оқытушыға (практикант Елеуберген Ж.А. / практика жетекшісі Байбактина А.Т.)
бақылау үшін арналған. `index.html`, `style.css`, `script.js` файлдарының ешқайсысы
бұл файлға сілтеме бермейді және оның мазмұнын студент бетіне шығармайды.

## Практикалық тапсырмалар (4-бөлім) — жауаптары

1. `numbers = [4, 6, 4, 8, 6, 9]` → `sorted(set(numbers))` → `[4, 6, 8, 9]`
2. `A = {2, 4, 6, 8}`, `B = {4, 7, 8}` → қиылысуы `{4, 8}`, айырымы (A-B) `{2, 6}`
3. `student = {'name': 'Dina', 'score': 75}` → `student['score'] = 85`,
   `student['dept'] = '...'` (кез келген бөлім атауы) → `name` = `'Dina'`, `score` = `85`

## Зертханалық нұсқалар — толық жауаптар

### 1-нұсқа
- Жиын: `A = {2,4,6,8,10}`, `B = {3,6,9,12}` → қиылысуы `{6}`, бірігуі
  `{2,3,4,6,8,9,10,12}`.
- Сөздік: жалпы құны = `350*5 + 900*2 + 1200*3 + 1500*1 = 8650`. Мерзімі 3 айдан
  артық (`мерзімі > 3`): Парацетамол (8), Сироп (6). (Спрей — мерзімі дәл 3, сондықтан
  «3 айдан артық» шартына кірмейді.)

### 2-нұсқа
- Жиын: `A = {5,7,10,11,15,20,24}`, 5-ке еселі (5,10,15,20) жойылады →
  қалғаны `{7,11,24}`.
- Сөздік: 1990-нан кейін туылған (`жылы > 1990`): Әлиев Данияр (1994),
  Қабылбек Ару (2003). Жалпы саны — 2. (Омар Елдос 1990 жылы туған,
  шартқа кірмейді.)

### 3-нұсқа
- Жиын: `A = {2,6,8,9}`, `B = {3,6,9}` → бірігуі `{2,3,6,8,9}`, айырымы (A-B)
  `{2,8}`.
- Сөздік: жылы бойынша өсу ретімен — Алгоритмдер (2017), Программалау (2019),
  Python негіздері (2020), Деректер (2023). Бағасы бойынша өсу ретімен —
  Деректер (3000), Python негіздері (3800), Алгоритмдер (4200),
  Программалау (5500).

### 4-нұсқа
- Жиын: `A = {4,7,10,12}`, ең кіші элемент — 4, оны B-ға қосу → `B = {1,4,9}`
  (A өзгермейді: `{4,7,10,12}`).
- Сөздік: әйел адамдар — Айгүл (телефон 111-22-33, Ақтөбе 1-үй),
  Дина (телефон 333-44-55, Ақтөбе 3-үй).

### 5-нұсқа
- Жиын: `A = {3,5,6,9,11,14}`, K=3-ке еселілерді жою (3,6,9) → қалғаны
  `{5,11,14}`.
- Сөздік: бос орын > 100 — Астана №022 (132), Атырау №033 (101).

### 6-нұсқа
- Жиын: `A = {3,8,11,16}`, ең үлкен элемент — 16, оны B-ға қосу →
  `B = {1,4,16}` (A өзгермейді).
- Сөздік: ер адамдар — Ержан (программист, 27), Бекзат (инженер, 31).

### 7-нұсқа
- Жиын: A=4, B=11 аралығындағы бүтін сандар (екі шеті қоса) →
  `{4,5,6,7,8,9,10,11}`.
- Сөздік: алфавит бойынша — Айсұлтан (2005), Бекзат (2004), Данияр (2006),
  Мақсат (2005).

### 8-нұсқа
- Жиын: `A = {3,4,6,8,9,12,14}`, 3-ке еселілер → `{3,6,9,12}`.
- Сөздік: Қасымов Айдар (ер) — темекі шекпейді; Омарова Дина (әйел) — көз
  түсі қоңыр; Беков Самат (ер) — темекі шегеді; Әлиева Айжан (әйел) — көз
  түсі көк.
