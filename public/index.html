1

Бастау

Ұсынылған уақыт: ≈ 5 минут · Осы кезеңде: сабақтың мақсаты мен мәселесімен танысасыз

Бүгінгі мақсат

Бүгін біз шағын әзірлеушілер командасы ретінде жұмыс істейміз. Бір есептеуді қайта-қайта жазбай, оны функцияға айналдырамыз. Сабақ соңында әрқайсыңызда өз функцияңыз, үш тексеру мысалыңыз және нәтижені түсіндіретін қысқа жауабыңыз болады.

Сабақ соңында тапсырамын

  • Python коды (өз нұсқама арналған функция)
  • Үш тест нәтижесі
  • Қысқаша түсіндіру (функция қалай жұмыс істейтіні туралы)
  • Серіктесіме берген кері байланыс

Проблемалық жағдаят

Сервисте үш тапсырыстың құны есептеледі. Баға мен сан әртүрлі, бірақ есептеу әрекеті бірдей.

total_1 = 1500 * 2
total_2 = 2000 * 3
total_3 = 1200 * 4
print(total_1, total_2, total_3)

Талқылау сұрақтары

  1. Барлық есептеуде қандай әрекет қайталанып тұр?
  2. Әр есептеуге 10% жеңілдік енгізу керек болса, неше жолды өзгертеміз?
  3. Есептеу ережесін бір рет жазып, әртүрлі деректермен қолдануға бола ма?

Әр жолда бірлік бағасы мен саны көбейтіледі — бұл есептеу ережесі үш жерде де қайталанып жазылған. Ереже бірдей болса да, оны әр жолда қайта теру қатені көбейтеді: мысалы, жеңілдік қосу үшін үш жолды да өзгерту керек болар еді. Ортақ әрекетті бір рет жазып, оны әр түрлі деректермен (price, quantity) қайта-қайта шақыруға болады — дәл осыны функция істейді.

2

Түсіну

Ұсынылған уақыт: ≈ 8 минут · Осы кезеңде: функция теориясын оқып, мысалды орындайсыз

Функция не үшін қажет?

Алдыңғы бөлімдегі мысалда бірдей әрекет (бағаны санға көбейту) үш рет қайталанды. Функция — шақырылғанда белгілі бір әрекетті орындайтын код бөлігі. Ережені бір рет жазып, оны әртүрлі деректермен қайта-қайта қолдануға мүмкіндік береді.

Функция қалай анықталады? Параметр мен аргумент деген не?

def сөзі функцияны анықтайды. Жақшаның ішінде жазылған атаулар — параметрлер. Параметр функцияны анықтағанда жазылады. Аргумент функцияны шақырғанда беріледі.

Функцияны анықтау оның денесін бірден орындау емес. Төмендегі мысалда функция денесі тек функция шақырылғанда орындалады.

Функция қалай шақырылады? return не істейді? print() пен return несімен ерекшеленеді?

Функция атауын жазып, жақшаның ішіне керек аргументтерді беру арқылы шақырылады. return есептелген мәнді функция шақырылған орынға қайтарады — осы мәнді айнымалыға сақтап, кейін қолдануға болады. print() тек экранға шығарады, ал мән ешқайда сақталмайды.

Python ортасы жүктелуде…

    


    

      
Жолдар бойынша түсіндірме

      

        
1-жол — def calculate_total(price, quantity):

        
def функцияны анықтайды. calculate_total — функция атауы. price және quantity — параметрлер. Соңында қос нүкте қойылады.

        
2-жол — amount = price * quantity

        
Функция денесінде баға мен саны көбейтіліп, amount айнымалысына жазылады. Шегініс осы жолдың функцияға тиесілі екенін көрсетеді.

        
3-жол — return amount

        
return есептелген amount мәнін қайтарады.

        
5-жол — subtotal = calculate_total(1500, 2)

        
Функция 1500 және 2 аргументтерімен шақырылады. Қайтарылған 3000 мәні subtotal айнымалысына сақталады.

        
6-жол — total = subtotal + 200

        
Қайтарылған нәтижеге функцияның сыртында 200 қосылады.

        
7-жол — print(total)

        
print(total) соңғы 3200 нәтижесін экранға шығарады.

      

    

  


  

    
Шағын әрекет

    
Аргументтерді 1000 және 4 деп өзгертіңіз. Соңғы нәтиже қандай болады? Алдымен болжаңыз, кейін тексеріңіз.

    
    

  


  

    
Жеке жұмысқа өту

    
Жеке жұмыста price пен quantity параметрлеріне discount параметрін қосамыз. Ол жеңілдік пайызын білдіреді.

    
сома = price × quantity × (1 − discount / 100)

Болжау

        
Ұсынылған уақыт: ≈ 5 минут · Осы кезеңде: нәтижені алдын ала болжап, содан соң тексересіз

      

    

  


  

    
Орындамай тұрып болжа

    
Алдымен екі сұраққа жауап жазыңыз, содан кейін ғана кодты орындау және түсіндірмені ашу батырмалары белсенді болады.

    

      
      
    


    

      

        
        
        
        
      

      
      
Алдымен екі болжамды толтырыңыз

      

    


    
    

      
Экранда:

      
3000
None

      
3000 мәнін функция ішіндегі print() шығарады. Есептелген санды қайтаратын return болмағандықтан, бұл функцияның нәтижесі None болады және result айнымалысына None сақталады.

      
Экранда санның көрінуі оның функциядан қайтарылғанын білдірмейді. print() көрсетеді, ал return нәтижені кейін қолдану үшін қайтарады.

    

  


  

    
Түзету тапсырмасы

    
Функция есептелген санды қайтарсын. Оны айнымалыға сақтап, функцияның сыртында 200 қосыңыз. Бастапқы кодты өзіңіз түзетіп, орындап көріңіз.


    

      

        
        
        
        
        
      

      
      
Python ортасы жүктелуде…

      

    


    
    

      
def calculate_total(price, quantity):
    return price * quantity

result = calculate_total(1500, 2)
total = result + 200
print(total)

      
Нәтиже: 3200.

Менің нұсқам

        
Ұсынылған уақыт: ≈ 15 минут · Осы кезеңде: оқытушы белгілеген нұсқада жеке функция жазасыз

      

    

  


  

    
    

  


  

    
Ортақ тапсырма

    
Өз нұсқаңызда берілген атаумен үш параметрлі функция құрыңыз:

    
    
      
  • price — бірлік бағасы;
    • 
      
  • quantity — саны немесе мерзімі;
    • 
      
  • discount — жеңілдік пайызы.
    • 
    

    
Жеңілдіктен кейінгі соманы есептеп, return арқылы қайтарыңыз. Функцияны шақырып, нәтижені айнымалыға сақтаңыз. Функцияның сыртында сол нәтижеге fee қызмет ақысын қосыңыз. Сома мен соңғы төлемді бөлек шығарыңыз.

    
сома = price × quantity × (1 − discount / 100)
соңғы төлем = функция қайтарған сома + fee
